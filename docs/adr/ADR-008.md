# ADR-008: Runtime and Local Configuration

Status: Accepted

## Context

Use current stable LTS without editing user global configuration.

## Decision

Java 25, Spring Boot 4.1.1, Spring AI 2.0.1, Next.js 16.4.0; project-local tools/cache.

## Consequences

Profile settings are ephemeral via API; env/YAML persists across restart. Mock is the default. See upstream release sources below.

Sources: https://docs.spring.io/spring-ai/reference/getting-started.html ; https://www.oracle.com/java/technologies/downloads/ ; https://nextjs.org/blog
